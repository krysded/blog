# blog

Hugo blog at https://vratislav.svejdovi.org, deployed by Cloudflare Workers Builds on every push to `main`.

## New post

Create `content/posts/my-post.md`:

```markdown
---
title: "My post"
date: 2026-11-24
---

Text in Markdown.
```

Commit and push — that's it. (Add `draft: true` to keep it unpublished.)
With Hugo installed locally: `hugo new posts/my-post.md`, preview with `hugo server -D`.

## Cloudflare settings

- Build command: `hugo --gc --minify`
- Deploy command: `npx wrangler deploy` (reads `wrangler.jsonc`, uploads `public/`)

## Layout

TUI-style site: own templates in `layouts/`, CSS in `static/style.css`, keyboard navigation in `static/tui.js`
(j/k, Enter, h/Esc back, Tab switch pane, g/G, 1–4 sections, / search, ? help). Every row is a normal link,
so the site works without JavaScript; search reads `/index.json`, generated by `layouts/home.json`.

- Tags: add `tags: ["linux"]` to a post's front matter.
- Projects: add a `[[project]]` entry to `data/projects.toml` (shows on /projekty/ and in search).
- About page: `content/o-mne.md`.
